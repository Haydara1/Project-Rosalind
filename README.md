## About

This repository contains my solutions to the bioinformatics and programming challenges from [Project Rosalind](https://rosalind.info/), implemented in **C#**.

[Rosalind](https://rosalind.info/) is an educational platform designed to teach bioinformatics through problem-solving. It combines programming and computational thinking with fundamental concepts in molecular biology, genetics, and evolutionary biology.

The goal of this repository is to document my progress, strengthen my programming skills, and explore the algorithms and mathematical concepts used in bioinformatics.

## Technologies

- **Language:** C#

## Problem Categories

The challenges cover a variety of topics, including:

- **String Algorithms:** DNA and RNA manipulation, pattern matching, and sequence analysis.
- **Counting and Combinatorics:** Counting nucleotides, permutations, and combinatorial problems.
- **Probability:** Random variables, probability distributions, and genetic probability.
- **Genetics:** Mendelian inheritance, DNA replication, transcription, and translation.
- **Graph Theory:** Genome assembly, overlap graphs, and phylogenetics.
- **Dynamic Programming:** Sequence alignment and optimization problems.
- **Algorithms:** Sorting, searching, recursion, and computational complexity.

## Running the Solutions

Make sure you have the [.NET SDK](https://dotnet.microsoft.com/download) installed.

Clone the repository:

```bash
git clone https://github.com/Haydara1/Project-Rosalind
cd Project-Rosalind
```

Navigate to the desired solution directory and run its project:

```bash
cd Problems
dotnet run
```

*Running commands may vary depending on the project structure.*
